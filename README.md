# 潮汐獵手 Tide Hunter

結合「釣魚 × 收服養成 × 肉鴿」的像素風網頁遊戲。

目前版本：**M1 戰鬥核心**（海域 1「碧藍淺灘」，共 9 站，最後挑戰霸主）。

## 開始

```bash
npm install
npm run dev      # 開發模式，會顯示本機與區網網址（手機可直接連）
npm run build    # 型別檢查＋打包到 dist/
npm run preview  # 預覽打包結果
```

## 部署

推到 `main` 分支時，GitHub Actions 會自動打包並部署到 GitHub Pages（設定在 `.github/workflows/deploy.yml`）。
第一次使用前，要在儲存庫的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

## 版本與更新通知

- 每次更新都要在 `src/data/changelog.json` **最上面**加一筆（版本號、日期、更新項目）。主畫面的「📢 通知」會列出這些內容，右下角顯示目前版本
- 打包時會輸出 `version.json`。正在玩的人每分鐘檢查一次，發現新版本時：
  - 在主畫面、港口、圖鑑、玩法說明：倒數 5 秒後自動更新
  - 冒險途中：只在下方顯示「新版本已就緒」，不會打斷，回到主畫面才倒數更新

## 技術架構

| 部分 | 技術 |
|---|---|
| 介面 | Preact（TSX），以「遊戲視窗」的形式疊在場景上 |
| 場景、戰鬥、釣魚、進化演出 | Canvas 2D，256×144 低解析度放大成像素風 |
| 建置 | Vite + TypeScript |
| 存檔 | localStorage（每站自動存檔、圖鑑） |

```
src/
├─ data/        純資料：屬性相剋、稀有度、技能、生物、像素圖
├─ game/        純邏輯：戰鬥引擎、生物成長、冒險流程、種子亂數
├─ render/      Canvas 繪圖：像素生物、海面場景、進化演出
└─ ui/          Preact 畫面：標題、航程、釣魚、戰鬥、收線、戰後、圖鑑
```

## 畫面設計

- **整個畫面就是遊戲**：固定 16:9 的主畫面，所有介面都是浮在場景上的遊戲視窗。尺寸以 `--u`（場景的一個像素）為單位，跟著螢幕縮放。
- **直式手機**：改成掌機的上下雙螢幕。上螢幕是場景，下螢幕放訊息、指令與大型視窗。
- **場景**：夕陽標題、海圖航線、白天海面（雲、遠島、透視波浪、陽光倒影）、戰鬥地形（前景沙洲、遠方礁岩）、海底（光束、海草、氣泡）。
- **生物繪製**：五階明暗與棋盤格過渡、朝光側彩色外框、背光側邊緣光。一般生物 48×48，傳說級 64×64。
- **光環**：S、SSR 與霸主在戰鬥中有脈動的發光外框與上升的能量粒子。

## 美術

- **美術包**：`tide-hunter-美術包.zip`（也就是 `art-pack/` 資料夾）有所有角色與場景圖層的 PNG、規格說明、角色總覽與清單
- **換圖**：把 PNG 放進 `src/art/sprites/<角色代號>.png` 或 `src/art/scenes/<名稱>.png`，就會取代程式畫的版本（細節見 `art-pack/README.md`）
- **重新匯出**：`npm run dev` 後打開 `/dev/export.html`，可以把目前的美術重新輸出

## 開發小工具

- `dev/sheet.html`：所有生物的圖鑑預覽（`npm run dev` 後打開 `/dev/sheet.html`，可加 `?only=dragon,whale`）。
- 開發模式下，網址加 `?enc=形態id&lv=等級` 可以指定下一次釣到的生物，例如 `?enc=thunderfang&lv=8`。

## 為之後的連線合作／對戰預留的設計

- `game/battle.ts` 是**純邏輯**，不碰畫面，只吃「雙方的行動」並吐出「事件列表」。畫面只負責播放事件。
- 兩邊都是同樣的 `Side`；AI 只是其中一種操作者（`aiChoose`），之後換成連線玩家即可。
- 行動是可序列化的資料：`{ type: 'skill', slot: 2 }`、`{ type: 'switch', to: 1 }`……可直接透過網路傳送。
- 所有隨機都走 `game/rng.ts` 的種子亂數，狀態可 JSON 序列化。**同樣的初始狀態＋同樣的行動序列＝完全相同的結果**，連線時兩端只要交換行動就能同步，也方便做重播。

## 新增一隻生物

1. 在 `src/data/sprites.ts` 用圖元畫出 48×48 像素圖（朝右）。
2. 在 `src/data/creatures.ts` 加一筆 `Form`：屬性、稀有度、階段、能力值、特性、學習表、進化條件。
3. 想讓牠在野外出現，就把 id 加進對應海域的出現池。

技能在 `src/data/skills.ts`，特性效果在 `src/game/battle.ts`。

## 第一階段（基礎玩法）已完成

- **分岔航線**：每局隨機產生，每站 2–3 條岔路（釣點／精英釣點／寶藏點／營地／漂流商店），更遠的海域被迷霧遮住，打完一關才會看到下一站

- **收服判定**：收線成功後魚會在網裡晃動三次，每次都可能掙脫（看 HP、異常狀態、稀有度、收線表現）
- **釣魚**：海面有大小不同的魚影可以選、假咬鉤（浮標輕點水時拉竿會嚇跑魚）、寶箱與垃圾、四種釣點地形
- **能力卡**：每場勝利或收服後三選一（戰鬥／捕捉／釣魚／養成／回復），精英釣點的卡比較好
