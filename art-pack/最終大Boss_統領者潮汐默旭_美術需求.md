# 最終大Boss：統領者・潮汐默旭 美術需求

打完第三片海域的霸主後登場的最終大Boss。現在遊戲裡先用「蒼鱗龍」換色、放大 1.3 倍暫代，請畫一張專屬的圖。

## 角色設定

- **名稱**：潮汐・默旭（稱號：統領者／統領萬潮之人）
- **屬性**：水＋暗
- **稀有度**：UR（遊戲裡唯一的 UR，標籤是流動的彩虹色；戰鬥中身上的光環會一直變換顏色，設計時可以考慮「閃彩」的感覺）
- **定位**：大海本身的看守者。所有海域的霸主（鯨嘯、冰冠海豹王、熔岩海龍王、主機海皇、冥海巨鯨）都是「聽著祂的潮聲長大的」。祂一直在最深的海裡，等一個配得上「潮汐獵手」之名的人。
- **個性**：沉穩、威嚴，但不是邪惡的。打贏後祂會認可玩家，化成光點回到每一片海域。
- **代號**：`tide_moxu`

## 外型方向（建議）

- 要一眼看出「比所有霸主都高一階」：體型最大、輪廓最複雜。
- 身上融合五片海域的元素，暗示祂統領所有海：
  - 淺灘的珊瑚或浪花
  - 冰原的冰晶
  - 裂谷的熔岩紋
  - 資料海的發光線條
  - 深淵的暗色與微光
- 主色：深海藍、黑，配上破曉的金色光。結局時祂代表「天亮」，所以要有金色元素。
- 不要做成龍的翻版（暫代圖是龍），可以是巨大的海洋神獸、半人半潮的存在，或抽象的潮汐化身，請自由發揮。
- 必須是原創設計，不要像任何現有作品的角色。

## 規格（跟其他角色一樣）

| 項目 | 內容 |
|---|---|
| 主圖 | `sprites/tide_moxu.png`，6 格橫排待機動畫 |
| 色違 | `shiny/tide_moxu.png`，6 格（目前不會出現，但請一起畫，保持一致） |
| 每格大小 | 128×128（世界大小 64，2 倍高解析），跟 64 格的角色一樣 |
| 面向 | 面向右（遊戲裡會自動左右翻轉成面向左） |
| 對齊 | 腳底或身體最低點貼齊每格的底部往上 2 像素，6 格位置一致 |
| 動畫 | 慢速呼吸或漂浮，有潮水或光點在身邊流動 |
| sockets | 請照 `sprite_manifest.json` 的格式補上 mouth、claw、wing、foot、crown、core、body、ground 的座標，技能特效會用到 |

> 遊戲裡的戰鬥畫面會放大 1.3 倍，劇情畫面會放大到 1.5 倍，請確認放大後細節還是清楚。

## 會出現的畫面

1. **登場劇情**：在水牆中央，先是黑色剪影，再現出原本的顏色。
2. **最終決戰**：右上方的對手位置。
3. **結局劇情**：慢慢沉進海裡、半透明，最後化成光點。
