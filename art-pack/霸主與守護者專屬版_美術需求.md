# 霸主與守護者專屬版：美術需求

現在 5 隻海域霸主和 3 隻特殊區域的守護者，跟一般夥伴是一樣的大小（世界大小 64，藤角鹿甚至只有 48）。
在戰鬥中只靠紅色光環和「霸主」標籤區分，看起來不夠有份量。

請幫這 8 隻各畫一張**專屬版**：體型更大、細節更多，一眼就看得出是一片海域的王。
畫好後會直接取代牠們現在的圖（戰鬥、圖鑑、棲息灣都用新的）。

## 共通規格

| 項目 | 內容 |
|---|---|
| 檔案 | `sprites/<代號>.png`（6 格橫排待機動畫），`shiny/<代號>.png`（色違，6 格） |
| 每格大小 | **192×192**（世界大小 **96**，2 倍高解析） |
| 面向 | 面向右（遊戲會自動翻轉成面向左） |
| 對齊 | 最低點貼齊每格底部往上 2 像素，6 格位置一致 |
| 動畫 | 慢速、有重量感的待機（呼吸、鰭或觸手擺動、身上的光紋流動） |
| sockets | 照 `sprite_manifest.json` 的格式補上 mouth、claw、wing、foot、crown、core、body、ground 八個定位點 |
| 邊緣 | 不要半透明邊、不要光暈（跟上一批一樣） |

## 共通的「王者記號」

為了讓 8 隻有一致的辨識度，建議每隻身上都有：

- **王冠或冠狀結構**：可以是角、鰭、冰、晶體、光環等，各自用自己的屬性做出「冠」的形狀
- **海域紋章**：身上某處有一個發光的紋章，用該海域的代表色
- **比一般型態更多的裝甲／傷痕／歲月感**：看得出活了很久、打過很多仗

海域代表色：淺灘 #5fb4ff、冰原 #8ad8ff、裂谷 #ff7a2a、資料海 #5ff1ff、深淵 #9ad8ff、聖林 #4ab04a、無稽 #c89aff、域核 #5ff1ff

## 個別需求

### 1. 鯨嘯 `whale`（碧藍淺灘的霸主）
- 屬性：水｜類別：巨獸
- 設定：淺灘的霸主。一聲長嘯就能掀起巨浪。
- 專屬版方向：背上長出珊瑚與貝殼組成的「礁石王冠」，嘴邊有浪花，鰭上有淺灘藍的紋章。是 8 隻裡最「親切」的王，但體型壓迫感要夠。

### 2. 冰冠海豹王 `frostking`（冰封峽灣的霸主）
- 屬性：冰＋水｜類別：巨獸
- 設定：頭戴萬年不化的冰冠的巨型海豹。
- 專屬版方向：冰冠更巨大、更晶瑩，冰冠裡封著極光；身上覆蓋碎冰鎧甲，鬍鬚結霜。

### 3. 熔岩海龍王 `lavadragon`（熔岩裂谷的霸主）
- 屬性：火＋水｜類別：龍
- 設定：在岩漿與海水的交界處沉睡。
- 專屬版方向：半邊身體是黑曜岩鎧甲、裂縫流著岩漿，另一半是蒸氣與海水；頭上有熔岩角冠。

### 4. 主機海皇 `mainframe_leviathan`（電子海域的霸主）
- 屬性：資料＋電｜類別：龍
- 設定：胸口的核心處理器是整片資料海的心臟。
- 專屬版方向：核心處理器更大、會發光閃爍；身上有電纜像鬃毛一樣飄動，頭上是由螢幕框組成的冠。

### 5. 冥海巨鯨 `nether_whale`（深淵的霸主）
- 屬性：暗＋水｜類別：巨獸
- 設定：全身佈滿傷痕的遠古巨鯨，張開嘴就是一片星空。
- 專屬版方向：傷痕更多更深、裡面透出微光；嘴裡的星空更明顯；身上附著古老的船骸或鐘。

### 6. 藤角鹿 `vine_antler_deer`（聖林域的守護者）
- 屬性：草｜類別：巨獸
- 設定：鹿角上纏繞的藤蔓會開出花。
- 專屬版方向：**目前只有 48 大小，這隻最需要放大**。鹿角變成一整棵開花的樹，腳邊長出草與花，身上有聖林綠的紋章。

### 7. 虛無星龍 `void_star_dragon`（無稽區的守護者）
- 屬性：暗＋飛｜類別：龍
- 設定：鱗片上倒映著不存在的星空。
- 專屬版方向：翅膀張開、翼膜是一片會流動的星空；身體輪廓有一部分是「缺掉」的虛空，頭上有破碎星辰組成的冠。

### 8. 域界核心 `domain_realm_core`（域核區域的守護者）
- 屬性：資料｜類別：抽象
- 設定：環繞著它的光帶就是區域的邊界。
- 專屬版方向：光帶增加到多層、互相交錯旋轉；核心周圍漂浮著碎裂的立方體，整體像一座小型的「世界」。

## 優先順序

1. **藤角鹿**（現在最小，差距最明顯）
2. **五隻海域霸主**（每局都會遇到）
3. **虛無星龍、域界核心**（只在特殊區域遇到）
