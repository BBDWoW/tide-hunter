# 潮汐獵手 美術包

這裡是遊戲目前所有的美術圖，可以直接拿去修改（自己畫、或交給 AI 繪圖工具重繪）。
改好的圖放回遊戲對應的資料夾，就會**自動取代**原本的版本；沒有放圖的角色會沿用原本程式畫的樣子，所以可以一隻一隻慢慢換。

## 資料夾內容

| 檔案 | 說明 |
|---|---|
| `角色總覽.png` | 所有角色一覽，方便對照名稱和檔名 |
| `角色清單.csv` | 檔名、角色名稱、尺寸、稀有度、配色（Excel 可直接開） |
| `sprites/` | 每隻角色的**原始尺寸**圖（48×48 或 64×64），改這裡的就對了 |
| `sprites_2frames/` | 每隻角色的**兩格待機動畫**（左右並排，96×48 或 128×64） |
| `scenes/` | 場景的靜態圖層（見下方） |
| `preview_x4/` | 放大 4 倍的預覽圖，只是方便看，**不要拿這個放回遊戲** |
| `palettes.json` | 目前每一套配色的色碼 |

## 角色圖規格

| 項目 | 規格 |
|---|---|
| 尺寸 | 一般角色 **48×48**；傳說級、霸主 **64×64**（照 `角色清單.csv`） |
| 背景 | **透明 PNG** |
| 方向 | **面向右邊**（敵人在遊戲裡會自動翻轉成面向左） |
| 風格 | 像素風，**不要模糊、不要半透明柔邊** |
| 動畫 | 可以只給 1 格；要待機動畫就把 2 格**左右並排**（寬 = 高 × 2） |
| 檔名 | 跟 `sprites/` 裡的檔名一樣，例如 `water1.png`、`dragon.png` |

- 尺寸以**圖片的高度**為準。如果想把某隻改大（例如 48 改 64），直接畫成 64×64 也可以。
- 用圖片取代後，遊戲**不會再自動加明暗與外框**，請在圖裡畫好。
- 同一張圖如果有「異變配色」，目前會直接用你畫的顏色，不會自動換色。

## 場景圖層規格

| 檔名 | 尺寸 | 說明 |
|---|---|---|
| `bg-day.png` | 256×144 | 白天海面（淺灘的戰鬥與釣魚） |
| `bg-sunset.png` | 256×144 | 夕陽海面（標題畫面） |
| `bg-ice.png` | 256×144 | 冰封峽灣 |
| `bg-lava.png` | 256×144 | 熔岩裂谷 |
| `shoal-day.png`／`-ice`／`-lava` | 120×30 | 戰鬥時我方站的平台 |
| `reef-day.png`／`-ice`／`-lava` | 80×26 | 戰鬥時敵方站的礁石 |

背景只取代**靜態的天空與海面**。雲、波浪、雪花、火星等動畫還是由遊戲疊在上面。

## 改好之後怎麼放回遊戲

| 種類 | 放到這個資料夾 |
|---|---|
| 角色圖 | `src/art/sprites/` |
| 場景圖層 | `src/art/scenes/` |

放進去之後推上 GitHub，網站會自動更新。也可以直接把圖片傳給 Claude，請它幫你放進去。

如果交給 AI 畫的圖尺寸不精準、背景不是透明，或邊緣有模糊，也可以直接丟給 Claude，它會幫你縮成正確的像素尺寸、去背景、清掉模糊的邊緣。

## 給 AI 繪圖工具的提示範例

> 請參考附圖，重新繪製這隻角色的像素圖。48×48 像素、透明背景、面向右邊、清楚的深色外框、不要模糊和半透明邊緣、顏色數量控制在 16 色以內，保留原本的造型特徵和配色。
